## Production Changes

**P0 — app crashed on every single launch (PR #117, commit
`2fe793de`).** Found by following this project's own real-artifact-
validation requirement before tagging: built the actual release binary
and it crashed immediately on launch. `BrainManager::start_health_monitor`'s
`tokio::spawn` (`sidecar.rs`) was called from `start_brain()`, a plain
sync fn with no Tokio runtime active on the calling thread — every
launch hit `there is no reactor running, must be called from the context
of a Tokio 1.x runtime` inside tao's macOS app-delegate callback, a
non-unwinding panic that aborted the whole process. This would have
shipped to every user had the artifact not been built and launched
before tagging. Fixed by explicitly entering the runtime via
`tauri::async_runtime::spawn` before calling `start_health_monitor`, the
same pattern already used three lines above for `manager_clone.start()`.

**Security (P0/P1), PR #115:**
- Desktop: closed two path-traversal bugs (arbitrary file read via
  unvalidated kubeconfig path param, arbitrary file write via
  unsanitized export filename); scoped `shell:allow-execute` to no args
  for both sidecars.
- Backend: secret-redaction case-sensitivity bypass closed; RBAC added
  to Events/OTel routes, file browser, scanner, report schedules (all
  previously under-gated).
- OIDC nonce replay protection + fixed a broken SAML ACS flow (never
  actually read the POST body).
- Node drain now requires destructive-action confirmation.

**Backend reliability, PR #115:**
- ~40 production goroutines (main HTTP server, every WebSocket client
  pump, AI chat gRPC pump, cluster discovery watchers, addon rollout
  orchestrator, etc.) now carry panic recovery via a new centralized
  `safego.Go()` wrapper — previously only 1 of them did, despite docs
  claiming otherwise.
- Informer-cache: added APIService, VerticalPodAutoscaler, and DRA
  (ResourceSlice/DeviceClass) caching with per-kind sync isolation;
  fixed a VPA-not-installed log-spam bug found via live testing.
- Blast-radius: O(1) pod/edge lookups + shared BFS (22x faster),
  automatic recovery from cold-start instead of giving up forever, 15s
  request-level timeout watchdog.
- Topology: fixed `AggregatePods`' backwards edge-direction assumption
  (root cause of UI freezing on large clusters), routed V1 engine +
  resource-topology + cluster-summary/fleet-overview through the
  informer cache.
- Cluster detection: fixed an unreachable-cluster identity-collision
  freeze (root cause of a documented app-freeze incident),
  presence/discovery state propagation fixes.

**Frontend, PR #115:**
- Deleted 12 confirmed-dead, unrouted pages (~6,400 LOC) including an
  orphaned login/password-reset frontend with no backend entry point.
- Fixed a divide-by-zero that rendered literal "Infinity%"/"NaN%" to
  users.
- Surfaced several silent-zero bugs (failed fetches rendering as
  empty/0 with no error indication) across `ServiceDetail`,
  `NetworkPolicyDetail`, dashboard widgets, and 3 high-fan-out shared
  list-page hooks.
- Gated Sentry init behind the analytics-consent flag (previously
  initialized unconditionally regardless of user consent).
- Namespace filter UI standardized across all 29 list pages; PVC
  browser directory listing capped + streaming downloads instead of
  buffering.
- Migrated vitest 2→4 + vite 5→6, clearing 2 critical dev-only CVEs.

**Test coverage, PR #115:** real coverage added for the generic
resource mutation path (Delete/Patch/Apply across multiple kinds +
RBAC/unknown-kind edge cases), Login's MFA branch (previously zero
coverage on an auth-bypass-risk path), pod exec/shell/PTY
stream/port-forward, CronJob trigger/Job retry, one real e2e
destructive-action test (ConfigMap delete to completion), Pods/
Deployments delete/bulk-delete/scale flows.

**Process/docs, PR #113/#114/#115:** `docs/ai/STABILIZATION-PLAN.md`
closed out against actual code; changelog backfilled for missing
v1.2.0/v1.2.2/v1.2.3 sections and the recurring-PR changelog workflow
bug fixed; `CODE_OF_CONDUCT.md`, LICENSE detection, and `.gitignore`
gaps closed; `cosign-installer@v4`→`@v3` CI pin (v4 never existed).

**Test-suite flakiness fix, PR #116:** `Pods.test.tsx`/
`Deployments.test.tsx` intermittently hit a 10s hook timeout under the
full 121-file vitest run from CPU-contention under default per-core
fork parallelism, not a logic bug. Capped `maxWorkers` + raised
`hookTimeout`; verified via 3 consecutive clean full-suite runs.
